## Project use

Consult these documents for composition, action hierarchy, labels, validation,
and consistent theme roles. Material Design 3 remains the primary visual design
reference. shadcn/ui examples contain React/TypeScript and framework-specific
installation instructions; they are not directly usable Streamlit widgets.

No shadcn/ui package, React runtime, Tailwind configuration, or component source
has been installed into the application. Example code inside these documentation
files remains reference text. Any actual UI implementation follows AGENTS.md.

Some upstream Markdown includes MDX components and relative links. It remains
searchable locally but does not reproduce the website's interactive examples.
Use the source URL at the top of each file for the live example. Upstream
documentation and examples retain their original ownership and applicable terms.
