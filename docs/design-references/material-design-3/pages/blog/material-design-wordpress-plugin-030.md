<h4>You can learn more about the Material Design for WordPress plugin in <a href="https://material.io/blog/material-design-wordpress-plugin">this blog post</a>.</h4>
<p>With the <a href="https://github.com/material-components/material-design-for-wordpress/releases/tag/0.3.0">0.3.0 update</a> to the Material Design for WordPress plugin, you can now use <a href="https://wordpress.com/support/block-pattern/">Block Patterns</a>&nbsp;to compose beautiful layouts and reusable sections.</p>
<div style="text-align: center; position: relative; padding-bottom: 56.25%; max-width: 100%; height: 0;"><iframe style="border-radius: 16px; position: absolute; top: 0; left: 0; width: 100%; height: 100%;" src="https://www.youtube-nocookie.com/embed/8sW2l9arwhI" frameborder="0" allowfullscreen=""></iframe></div>
<h2>What are Block Patterns?</h2>
<p><a href="https://wordpress.com/support/block-pattern/">Block Patterns</a> are new components in WordPress that allow you to quickly build with templates for common layouts.</p>
<p>You can combine blocks to create complex and beautiful pages.</p>
<h2>How to add a Block Pattern</h2>
<p>Using the <a href="https://wordpress.org/gutenberg/">Gutenberg WordPress Editor</a>, you can add a new block pattern using the add icon on the toolbar, or from the editor.</p>
<p>&lt;mio-image index=0&gt;&lt;/mio-image&gt;</p>
<p>Selecting the &ldquo;Patterns&rdquo; tab and choosing &ldquo;Material Design&rdquo; in the dropdown will filter all the new Material Block Patterns.</p>
<p>&lt;mio-image index=1&gt;&lt;/mio-image&gt;</p>
<p>You can select or drag a pattern from the list to the editor and start to customize the content.</p>
<p>&lt;mio-image index=2&gt;&lt;/mio-image&gt;</p>
<p>Templates will automatically include placeholder text where necessary, which you can replace with your own content.</p>
<p>&lt;mio-image index=3&gt;&lt;/mio-image&gt;</p>
<h2>Theming</h2>
<p>Start by changing the starter style in the&nbsp; customizer (wp-admin &gt; Appearance &gt; Customize &gt; Material Design Options).</p>
<p>&lt;mio-image index=4&gt;&lt;/mio-image&gt;</p>
<p>Now navigate to any page and start editing in the Gutenberg editor.</p>
<p>&lt;mio-image index=5&gt;&lt;/mio-image&gt;</p>
<p>With the Crane theme active all the Material Block Patterns will show a preview of the correct theme.</p>
<p>&lt;mio-image index=6&gt;&lt;/mio-image&gt;</p>
<p>By adding a block pattern to the page you can start to edit any component that makes up the pattern just like Material Blocks.</p>
<p>Both Material Block Patterns and Material Blocks can be themed and customized to the design of your choice.</p>
<p>There are a lot of patterns to choose from. Here&rsquo;s a full list:</p>
<ul>
<li>Call to action</li>
<li>Call to action + benefit</li>
<li>Contact form</li>
<li>Features + CTA</li>
<li>Numbers</li>
<li>Hero section</li>
<li>Hero section + image</li>
<li>Latest posts</li>
<li>Highlights</li>
<li>Feature list</li>
<li>Logos</li>
<li>Media grid</li>
<li>Single feature</li>
<li>Single feature extended</li>
<li>Pricing</li>
<li>If you have an idea for a new block pattern you can discuss it on the <a href="https://github.com/material-components/material-design-for-wordpress/discussions/157">Github repo</a>!</li>
</ul>
