<p><strong>Announcing the Alpha release of <a href="https://relay.material.io/" target="_blank" rel="noopener">Relay</a>&nbsp;</strong>&ndash; a new workflow for fast, seamless designer-developer handoff of Android UI components.</p>
<p>To dive in check out <a href="https://goo.gle/relay-ads-22" target="_blank" rel="noopener">our latest update from ADS 2022</a>, and get started with the <a href="https://www.figma.com/community/plugin/1041056822461507786" target="_blank" rel="noopener">Relay for Figma Plugin</a>. Full documentation is available on the <a href="https://developer.android.com/jetpack/compose/tooling/relay" target="_blank" rel="noopener">Android developers site</a>.</p>
<h2>What&rsquo;s Relay?</h2>
<p>Relay allows teams to design UI components in Figma and directly use them in Android apps.</p>
<p>The Relay workflow consists of plugins for both Figma and Android Studio. Designers use the Relay for Figma plugin to annotate and package UI components for developer use, including information about layout, styling, dynamic content and interaction behavior. These UI Packages provide a shared model for UI components, and can be exchanged and updated in a collaboration between designers and developers.</p>
<p>Developers use the Relay for Android Studio plugin to import UI Packages and generate pixel-perfect Jetpack Compose code. This process provides instant layout and styling implementation, and speeds up the process of binding data without ever touching a design spec. UI Packages can include styles and themes, and reference design system components that exist as code, while maintaining a link to Figma for fast updates to components. Feedback from early access adopters shows a 10x acceleration in a team&rsquo;s time to their first UI implementation, and further iterations come faster too.</p>
<h2>Get involved</h2>
<p>Relay is an Alpha product, and we&rsquo;re excited to hear from you and your team! We hope you&rsquo;ll join the community of designers and developers adopting Relay, share <a href="https://goo.gle/relay-feedback" target="_blank" rel="noopener">feedback</a> and let us know how we can make Relay even better.</p>
<p>Sign up for <a href="https://goo.gle/relay-newsletter" target="_blank" rel="noopener">Relay&rsquo;s mailing list</a> to get the latest news and connect with our team &ndash; and look out for our <a href="https://www.youtube.com/MaterialDesign" target="_blank" rel="noopener">livestream</a> on November 2nd for a deep dive into Relay&rsquo;s workflow.</p>
