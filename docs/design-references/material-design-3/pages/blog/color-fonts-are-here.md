<p>Even if you&rsquo;ve never heard of &ldquo;color fonts,&rdquo; you probably use them everyday; emoji are color fonts. Color fonts enable color specification within the font file&mdash;and one <a href="https://fonts.google.com/knowledge/glossary/glyph" target="_blank" rel="noopener">glyph</a> can have multiple colors. Non-color fonts (i.e., most existing fonts) only specify where color goes. A glyph can only be one color, and if you want your type to be something other than black, you have to manually change it.</p>
<p>Emoji is the most obvious use case for color fonts, but type designers are running with this technology to make highly expressive and customizable typefaces&mdash;especially in the newest format, COLRv1.</p>
<p>We&rsquo;re so excited about color fonts, we even added a search filter for them on <a href="https://fonts.google.com/" target="_blank" rel="noopener">Google Fonts</a>.</p>
<h2>What&rsquo;s so special about the COLRv1 font format?</h2>
<p>There are a few things. First, COLRv1 is a binary vector format (unlike the bitmap color fonts of yore), which means fonts can scale without becoming pixelated. And by layering glyphs and then reusing those layers in similar glyphs, file sizes stay compact.</p>
<p>COLRv1, which is already available in both Chrome, Android, and the Google Fonts API, adds support for:</p>
<ul>
<li><strong>Gradients</strong><br />All the common CSS gradients are possible, and multiple gradients can be included in a single glyph.</li>
</ul>
<p>&lt;mio-image index=0&gt;&lt;/mio-image&gt;</p>
<ul>
<li><strong>Multiple color palettes<br /></strong>The typeface designer can choose to include multiple color palette options in the font for use in CSS (<code>base-palette</code>).</li>
</ul>
<p>&lt;mio-image index=1&gt;&lt;/mio-image&gt;</p>
<ul>
<li><strong>Color palette customization</strong><br />You can customize color palettes in CSS (<code>font-palette-values</code>).</li>
</ul>
<p>&lt;mio-image index=2&gt;&lt;/mio-image&gt;</p>
<ul>
<li><strong>OpenType <a href="https://fonts.google.com/knowledge/glossary/variable_fonts" target="_blank" rel="noopener">Variations</a></strong><br />With the ability to add variable axes too, the possibilities for customizing a COLRv1 font are literally infinite!</li>
</ul>
<p>&lt;mio-image index=3&gt;&lt;/mio-image&gt;</p>
<h2>See COLRv1 in action with nine new typefaces, available now on Google Fonts</h2>
<p>The ability to represent multiple colors within a font is an important advancement for expression and communication.</p>
<p>Traditionally, calligraphy was the highest form of Arabic art. And, as it has been used as much for beauty as communication since the earliest versions of the Quran, Arabic calligraphy is inherently colorful. But Arabic is also unique in its functional use of two-color glyphs to clarify pronunciation/add diacritics. Today, colors are still often used for this purpose to help people learn the language.</p>
<h4>1. <strong><a href="https://fonts.google.com/specimen/Reem+Kufi+Ink" target="_blank" rel="noopener">Reem Kufi Ink</a></strong> and 2. <strong><a href="https://fonts.google.com/specimen/Reem+Kufi+Fun">Reem Kufi Fun</a></strong> (Arabic and Latin alphabets)<br />Khaled Hosny (with Latin components by Santiago Orozco)</h4>
<p>Expanding on the Reem Kufi typeface, Reem Kufi Ink and Reem Kufi Fun are based on early Arabic Kufic calligraphy.</p>
<p>Reem Kufi Ink is inspired by designs of the late master of Arabic calligraphy Mohammed Abdul Qadir, who revived this art in the 20th century and formalized its rules. It uses color gradients as an artistic interpretation of what the ink flow of traditional calligraphy would look like when written with a nib (the pointed end of a pen) and ink.</p>
<p>&lt;mio-image index=4&gt;&lt;/mio-image&gt;</p>
<p>Reem Kufi Fun is weight-variable and is also based on early Kufic (Mushafi) models, but is retrofitted to the Fatimid Kufic grid and borrows from its forms.</p>
<p>&lt;mio-image index=5&gt;&lt;/mio-image&gt;</p>
<h4>3. <strong><a href="https://fonts.google.com/specimen/Aref+Ruqaa+Ink" target="_blank" rel="noopener">Aref Ruqaa Ink</a>&nbsp;</strong>(Arabic and Latin alphabets)<br />Abdullah Aref, Khaled Hosny, Hermann Zapf</h4>
<p>Aref Ruqaa Ink is an Arabic typeface inspired by the classical Ruqaa calligraphic style, which is the the most common type of handwriting in the Arabic script. The use of gradients creates the look of simple, hand-drawn calligraphy.</p>
<p>&lt;mio-image index=6&gt;&lt;/mio-image&gt;</p>
<h4>4. <strong><a href="https://fonts.google.com/specimen/Amiri+Quran" target="_blank" rel="noopener">Amiri Quran</a>&nbsp;</strong>(Arabic and Latin alphabets)<br />Khaled Hosny and Sebastian Kosch</h4>
<p>The <a href="https://fonts.google.com/?query=amiri" target="_blank" rel="noopener">Amiri</a> typeface family revives one of the few metal typefaces that were used in typesetting the Koran, a Naskh-style Arabic face. Amiri Quran adds color to reflect how the text appears in early 20th century printed versions of the scripture.</p>
<p>&lt;mio-image index=7&gt;&lt;/mio-image&gt;</p>
<h4>5. <strong><a href="https://fonts.google.com/specimen/Cairo+Play" target="_blank" rel="noopener">Cairo Play</a>&nbsp;</strong>(Arabic and Latin alphabets)<br />Mohamed Gaber, Accademia di Belle Arti di Urbino (Fine Arts Academy in Urbino, Italy)</h4>
<p>Cairo Play is a new, weight-variable color font and member of the Cairo family. Cairo&rsquo;s design is based on the Kufi calligraphy style. The Kufi style is the oldest style of Arabic calligraphy. Because it had to be drawn on parchment (before paper, which was much smoother, was widely available), its shapes are more angular than later, more cursive styles. This makes it perfect for balancing classic and contemporary tastes. Cairo Play&rsquo;s Arabic component has a wide glyph set that supports the Arabic, Farsi and Urdu languages.</p>
<p>&lt;mio-image index=8&gt;&lt;/mio-image&gt;</p>
<h4>6. <strong><a href="https://fonts.google.com/noto/specimen/Blaka+Ink">Blaka Ink</a>&nbsp;</strong>(Arabic and Latin alphabets)<br />Mohamed Gaber</h4>
<p>Blaka Ink, part of the experimental <a href="https://fonts.google.com/?query=blaka" target="_blank" rel="noopener">Blaka</a> family from Mohamed Gaber of Principle Design, is inspired by Kufic letterforms hand-drawn with a reed pen. Sharp edges, thick strokes, and gradients create a striking style and the appearance of overlapping ink strokes.</p>
<p>&lt;mio-image index=9&gt;&lt;/mio-image&gt;</p>
<h4>7. <a href="https://fonts.google.com/noto/specimen/Noto+Color+Emoji" target="_blank" rel="noopener"><strong>Noto Color Emoji</strong></a><br />Google</h4>
<p>Last Spring we debuted <a href="https://fonts.google.com/noto/specimen/Noto+Emoji?query=noto+emoji&amp;vfonly=true">Noto Emoji</a>, a variable, monochrome version of Noto Color Emoji. And now the chromatic version is available on fonts.google, too. Coinciding with the new Unicode 15.0 Update, this launch includes 21 new characters, bringing us to a total of 3,664 emoji! Thanks to COLRv1, you can customize them all. Go ahead and <a href="https://developers.googleblog.com/2022/09/updates-to-emoji-new-characters-animation-colors-and-more.html" target="_blank" rel="noopener">give the duck a whirl</a>.</p>
<p>&lt;mio-image index=10&gt;&lt;/mio-image&gt;</p>
<h4>8. <a href="https://fonts.google.com/specimen/Bungee+Spice" target="_blank" rel="noopener"><strong>Bungee Spice</strong></a>&nbsp;(Latin alphabet)<br />David Jonathan Ross</h4>
<p>This newest member of the urban signage-inspired Bungee family includes multiple gradients and color palettes for you to play with.</p>
<p>&lt;mio-image index=11&gt;&lt;/mio-image&gt;</p>
<h4>9. <strong><a href="https://fonts.google.com/specimen/Nabla" target="_blank" rel="noopener">Nabla</a>&nbsp;</strong>(Latin alphabet)<br />Arthur Reinders Folmer, Just van Rossum</h4>
<p>Nabla was inspired by isometric computer games (remember <a href="https://freeqbert.org/" target="_blank" rel="noopener">Q-Bert</a>?). It makes use of COLRv1 capabilities to create perspective, with smooth gradients, sharp highlights, and blended shadows. It includes multiple color palettes and two font variation axes&mdash;one for the depth of the letters, and another for the thickness of the highlight.</p>
<p>&lt;mio-image index=12&gt;&lt;/mio-image&gt;</p>
<p>Learn more about COLRv1 in &ldquo;<a href="https://developer.chrome.com/blog/colrv1-fonts/" target="_blank" rel="noopener">COLRv1 Color Gradient Vector Fonts in Chrome 98</a>&rdquo; on the Chrome Developers blog. <a href="https://fonts.google.com/?coloronly=true" target="_blank" rel="noopener">Try and download</a> all nine new color fonts on Google Fonts.</p>
