<p><a href="https://developer.android.com/events/dev-summit" target="_blank" rel="noopener">Android Dev Summit</a> is back for 2022, having kicked off today in the Bay Area, and Material Design is on the scene with exciting updates on Material.io, Material 3 components and libraries, and progress on tooling. There&rsquo;s a lot of news to cover, so we&rsquo;ve brought it all together in one post. Let&rsquo;s dig in!</p>
<h2>System Updates</h2>
<h4>Material.io</h4>
<p>First off, our site has been updated for Material Design 3, officially moving from the m3.material.io subdomain to the main attraction! If you&rsquo;ve taken a look around recently, you may have noticed that the official documentation for Material Design now makes more use of Material 3&rsquo;s principles. Dynamic color brings together the site&rsquo;s imagery and content, while the site itself demonstrates how the system can flex for product-specific use cases. Design Lead David Allin Reese points out the way new motion design contributes to the site&rsquo;s design refresh, allowing Material.io to &ldquo;express an energetic spirit through its motion, from changes in pixels to entire views.&rdquo; <a href="https://material.io/blog/material-io-redesign">Learn more</a> about the full breakdown of the design.</p>
<p>&lt;mio-image index=0&gt;&lt;/mio-image&gt;</p>
<h2>Libraries</h2>
<h4>Android Compose Stable Release</h4>
<p><a href="http://material.io/blog/material-3-compose-stable">Get the details</a></p>
<p>Material Design for Compose gets its first ever stable release, bringing with it all the building blocks you&rsquo;d expect &ndash; from dynamic color schemes to typography, components, shapes, and window size classes to help you build beautiful, usable, adaptable apps with Compose.</p>
<h4>Android Views 1.7.0 Stable Release</h4>
<p><a href="https://material.io/blog/android-stable-release-1-7-0">Get the details</a></p>
<p>The latest in our Android Views library includes updates to Material You styling, shape theming, accessibility, and size coherence, along with updated minimum requirements. Check out the full post for all the details.</p>
<h2>Tooling Updates</h2>
<p>We also have some news to share in the world of tooling, including a new and improved design kit and updates on our design-to-code workflow previewed at last year&rsquo;s summit.</p>
<h4>M3 Design Kit</h4>
<p><a href="https://material.io/blog/material-3-figma-design-kit">Get the details</a> | <a href="https://www.figma.com/community/file/1035203688168086460" target="_blank" rel="noopener">Grab the Design Kit</a></p>
<p>Our M3 design kit has been updated with all the UI elements, components, and styles you need to get started with Material Design 3. The design kit now offers&hellip;</p>
<ul>
<li>28 UI components</li>
<li>169 Figma components in total</li>
<li>1,984 variants</li>
<li>429 styles</li>
</ul>
<p>&lt;mio-image index=1&gt;&lt;/mio-image&gt;</p>
<p>With the M3 design kit, you&rsquo;ll be starting with the very latest from our team, and our community page will continue to keep you up to date, so you&rsquo;re always working from a strong foundation. <a href="https://material.io/blog/material-3-figma-design-kit">Check out all the updates</a>, and <a href="https://www.figma.com/community/file/1035203688168086460" target="_blank" rel="noopener">grab the kit</a> to get started yourself!</p>
<h4>Simplifying Handoff with Relay</h4>
<p><a href="http://material.io/blog/relay-in-alpha">Get the details</a></p>
<p>Last year at Android Dev Summit, we showed <a href="https://material.io/blog/designtocode">a glimpse</a> into our approach to the handoff problem between design and dev; a workflow built to span across disciplines with a shared model for encoding and transporting design intent.</p>
<p>&lt;mio-image index=2&gt;&lt;/mio-image&gt;</p>
<p>Today, we have some updates to share, the first of which is a new name: Relay&nbsp; includes a set of plugins for Android Studio and Figma, is now in Alpha.</p>
<p>Check out the <a href="http://material.io/blog/relay-in-alpha">full announcement</a>, give the tools a try, and give us your <a href="https://relay.material.io/feedback" target="_blank" rel="noopener">feedback</a>!</p>
<p></p>
<h2>Stay Tuned</h2>
<p>Android Dev Summit will continue on November 9th with Form Factors and November 14th with Platform content, so stay tuned for more relevant sessions on the <a href="https://www.youtube.com/user/androiddevelopers" target="_blank" rel="noopener">Android Developers YouTube channel</a>, and make sure you&rsquo;re subscribed to <a href="https://youtube.com/materialdesign" target="_blank" rel="noopener">Material Design</a> for more live streams, tutorials, and updates as well.</p>
