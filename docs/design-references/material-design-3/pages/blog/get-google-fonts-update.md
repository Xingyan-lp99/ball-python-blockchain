<p>There are many different ways in which the more than 1,500 font families on Google Fonts can be utilized&mdash;you can download and install them on your machine, you can upload them to your own web server or you can use our API for your web, Android, Flutter or iOS project.</p>
<p>As the versatility of our font catalog has grown, so has the need for more guidance on how to get the fonts selected on Google Fonts. To simplify this experience, we&rsquo;ve updated our website to make it easier to get what you need and return to your project.</p>
<p><span style="text-align: center;">&lt;mio-image index=0&gt;&lt;/mio-image&gt;</span></p>
<h2>One simple button</h2>
<p>If you&rsquo;ve visited any retail website on the internet, the following will be very familiar (we just won&rsquo;t ask you for money, as all our listed fonts and icons are using open source licenses).</p>
<p>Visiting any font family page, you will now see one big &ldquo;Get font&rdquo; button. Just click the button to add the font family to your selection. No need to decide on specific weights or styles like you used to.</p>
<p>&lt;mio-image index=1&gt;&lt;/mio-image&gt;</p>
<p>From there, keep browsing and adding more fonts. Or click on the little tote bag in the top right corner to visit your font selection, which will show you a list of the fonts you&rsquo;ve chosen. Once you are done refining your selection, you can choose how you want to use those fonts. If you scroll down to the bottom section of the page, you will see our new &ldquo;How to use&rdquo; section, which provides useful links where you can learn more about all the ways you can use our fonts in Google products, on your own computer or in your project.</p>
<p>&lt;mio-image index=2&gt;&lt;/mio-image&gt;</p>
<h2>All weights, all styles</h2>
<p>Next to the code you&rsquo;ll find another version listing your font family selection. This time the font families are presented as cards that provide you with the functionality to optimize your API call.</p>
<p>Your API call will now include all the available&nbsp;<a href="https://fonts.google.com/knowledge/glossary/weight" target="_blank" rel="noopener">weights</a>&nbsp;and&nbsp;<a href="https://fonts.google.com/knowledge/glossary/style" target="_blank" rel="noopener">styles</a>&nbsp;of a static font family. By expanding the font family cards you can unselect specific styles that you don&rsquo;t need. This will optimize the performance of your website or app.</p>
<p><span style="text-align: center;">&lt;mio-image index=3&gt;&lt;/mio-image&gt;</span></p>
<h2>Full variable font axes</h2>
<p>The previous version of&nbsp;<a href="https://fonts.google.com" target="_blank" rel="noopener">fonts.google.com</a>&nbsp;made you select specific styles from the&nbsp;<a href="https://fonts.google.com/knowledge/glossary/axis_in_variable_fonts" target="_blank" rel="noopener">axes</a>&nbsp;included in our&nbsp;<a href="https://fonts.google.com/knowledge/glossary/variable_fonts" target="_blank" rel="noopener">variable fonts</a>&nbsp;that would be delivered as&nbsp;<a href="https://fonts.google.com/knowledge/glossary/instance" target="_blank" rel="noopener">static instances</a>. Now, important axes like&nbsp;<a href="https://fonts.google.com/knowledge/glossary/weight_axis" target="_blank" rel="noopener">weight</a>&nbsp;and&nbsp;<a href="https://fonts.google.com/knowledge/glossary/optical_size_axis" target="_blank" rel="noopener">optical size</a>&nbsp;will be delivered as full axes via the API by default. Other axes will be pinned to their default value only. By opening the font family card you can easily change that value or switch to using the full axis.</p>
<p><span style="text-align: center;">&lt;mio-image index=4&gt;&lt;/mio-image&gt;</span></p>
<h2>Get embed code</h2>
<p>If you&rsquo;re working on a web, Android, iOS or Flutter project, instead of downloading, you might want to use our API for&nbsp;<a href="https://web.dev/articles/api-for-fast-beautiful-web-fonts" target="_blank" rel="noopener">simplicity, optimized performance, smaller file sizes and to remain future-proof</a>.</p>
<p>Clicking the big &ldquo;Get embed code&rdquo; button will take you to the next page, where you can select the platform you&rsquo;re working on. Choosing Android or iOS will provide the best links for the relevant documentation on <a href="https://developer.android.com" target="_blank" rel="noopener">developer.android.com</a> and <a href="https://developers.apple.com" target="_blank" rel="noopener">developers.apple.com</a>. For Flutter and the web you&rsquo;ll find the code for your project right here for copy &amp; pasting.</p>
<p>For the web we&rsquo;ve added some optional CSS code in addition to the html for your <code>head</code> that you can use to style your text a little more easily.</p>
<p style="text-align: left;"><span style="text-align: center;">&lt;mio-image index=5&gt;&lt;/mio-image&gt;</span></p>
<h2 style="text-align: left;">Download all</h2>
<p style="text-align: left;">To <a href="https://fonts.google.com/knowledge/using_type/installing_and_managing_fonts" target="_blank" rel="noopener">install your font selection</a>, <a href="https://fonts.google.com/knowledge/using_type/self_hosting_web_fonts" target="_blank" rel="noopener">self-host them on your web server</a> or open them in a font editor to evolve them into a new typeface, you will want to download them.</p>
<p style="text-align: left;">Each font family listed will have the option to be downloaded individually. Though it&rsquo;s much easier to click the big &ldquo;Download all&rdquo; button to get them all at once in one handy zip file.</p>
<p style="text-align: center;"><span style="text-align: center;">&lt;mio-image index=6&gt;&lt;/mio-image&gt;</span></p>
<p>All these changes are based on feedback we&rsquo;ve received from our users. You&rsquo;ve told us that on the current site it can be hard to find the code for the API for example. Using variable fonts has also been harder than it needs to be. Results from extensive user testing have shown that today&rsquo;s updates address these challenges. We&rsquo;re very excited about these improvements and hope they will make your lives easier.</p>
<p>We&rsquo;d also love to hear your feedback&mdash;simply click on the little speech bubble on the bottom left corner on <a href="https://fonts.google.com" target="_blank" rel="noopener">fonts.google.com</a>.</p>
