<h2><span style="white-space:pre-wrap" id="isPasted">Usage</span></h2>

<p>Loading indicators use animation to grab attention, mitigate perceived latency, and indicate that an activity is in progress.<br /><br />They should be used when progress isn’t detectable, or when it’s not necessary to indicate how long an activity will take.<br /><br />While similar in function to circular progress indicators, loading indicators are a better alternative for short processes between 200ms and 5s.</p>

Loading indicator in loading state with “Getting your device ready...”.

<p><span style="white-space:pre-wrap">Use a loading indicator when a background process is running</span></p>

videoUrl: https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fm0fd0ml7-Loading_Indicator-B.mp4?alt=media

<p>Choose a loading or <app-froala-tooltip-element description="Progress indicators show the status of a process in real time." link-label="More on progress indicators" link-url="/m3/pages/progress-indicators/overview" should-open-link-in-new-tab="true">progress indicator</app-froala-tooltip-element> that corresponds to the expected wait time and type of process. <br /><br />If the wait is very long, consider allowing users to navigate away from the page while the process finishes up.</p>

<h2><span style="white-space:pre-wrap" id="isPasted">Responsive layout</span></h2>

<p>Loading indicators default to 48dp, but the size is flexible. It should be between 24dp to 240dp, depending on the placement and the breakpoint. Avoid exceeding the minimum and maximum sizes.<br /><br />The ratio between the container and the active indicator stays the same when resizing the loading indicator. <br /><br />Reserve very large progress indicators for large and extra-large windows, like desktop.</p>

Loading indicators can range from 24dps to 240dps.

<h3>Larger windows</h3><p>As the pane or window size grows, consider scaling the loading indicator as well, so it remains proportional in size to the empty space around it. The loading indicator shouldn’t exceed 240dp. </p>

<h2><span style="white-space:pre-wrap" id="isPasted">Behavior</span></h2>

<h3><span style="white-space:pre-wrap" id="isPasted">Pull-to-refresh</span></h3><p>The loading indicator is used in <a href="https://developer.android.com/develop/ui/compose/components/pull-to-refresh" target="_blank" rel="noopener noreferrer">pull-to-refresh</a> on Jetpack Compose only.<br /><br />Pull-to-refresh is an Android system feature that manually refreshes screen content with an action or gesture. It’s used at the beginning of lists, grid lists, and card collections where the most recent content appears.<br /><br />It’s best to use pull-to-refresh with dynamic content that can have frequent updates, where people have a high chance of seeing new content after refreshing.</p>

## Accessibility

<h2><span style="white-space:pre-wrap" id="isPasted">Use cases</span></h2>

<p>People should be able to do the following with assistive technology:</p><ul><li>Navigate to the loading indicator</li><li>Understand what progress the indicator is communicating</li><li>Initiate a content refresh without relying on a gesture</li></ul>

<h2><span style="white-space:pre-wrap" id="isPasted">Interaction &amp; style</span></h2>

<p>The active indicator, which displays progress, provides visual contrast of at least 3:1 against most container and surface colors.<br /><br />The indicator itself must have 3:1 contrast with the background, but the container does not.</p>

<p>When integrated into another component, such as a button, make sure that the active indicator provides a visual contrast of at least 3:1 against the other component.</p>

<h2><span style="white-space:pre-wrap" id="isPasted">Labeling elements</span></h2>

<p>Since the loading indicator is a visual cue, it needs an accessibility label to assist people who can't rely on visuals.<br /><br />It should use the <strong>progress bar</strong> accessibility role. Write a label describing the purpose of the loading indicator, such as <strong>loading news article</strong> or <strong>refreshing page</strong>.</p>

<p><span style="white-space:pre-wrap">Loading indicator labels should explain which items are loading</span></p>
