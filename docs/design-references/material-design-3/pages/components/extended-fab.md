<h2>M3 Expressive update</h2>

<p><strong>May 2025</strong></p><p>The extended FAB now has three sizes: small, medium, and large, each with updated type styles. These align with the <app-froala-tooltip-element description="Floating action buttons (FABs) help people take primary actions." link-label="More on FABs" link-url="/m3/pages/fab/overview" should-open-link-in-new-tab="true">FAB</app-froala-tooltip-element> sizes for an easier transition between FABs. The baseline extended FAB is no longer recommended and should be replaced with the small extended FAB. Surface and FABs are also no longer recommended. <a href="https://m3.material.io/blog/building-with-m3-expressive" target="_blank">More on M3 Expressive</a></p>

<p>Variants and naming:</p><ul><li><p>Added new sizes</p><ul><li><p>Small: 56dp</p></li><li><p>Medium: 80dp</p></li><li><p>Large: 96dp</p></li></ul></li><li><p>No longer recommended</p><ul><li><p>Baseline extended FAB (56dp)</p></li><li><p>Surface extended FAB</p></li></ul></li></ul><p>Updates:</p><ul><li><p>Adjusted typography to be larger</p></li></ul>

<h2 id="isPasted">Usage</h2>

<p id="isPasted">Use an extended FAB on screens with long, scrolling views that require persistent access to an action, such as a checkout screen. </p><p>Use it when label text helps understand the main action, or to add further emphasis to the button.</p>

<h3 id="isPasted">Additional emphasis</h3><p id="isPasted">The extended FAB can provide more emphasis and clarity to a product’s primary action. </p><p>Since it has room for both a text label and icon, the extended FAB can be effective where an icon alone is ambiguous. However, the relationship between an extended FAB's icon and label should be clear.</p>

Extended FAB labeled “find flights” with an airplane icon, which would be unclear on its own.

<p>An extended FAB can be effective where an icon alone is too vague</p>

<p id="isPasted">Like the regular FAB, only one extended FAB should be used per screen. </p><p>Multiple FABs compete for attention. </p><p>If additional high-level actions are required, consider adding more buttons elsewhere on the page.</p>

An extended FAB used on a screen.

<p>Only show one prominent action at a time with the extended FAB</p>

<h3>Choosing a size</h3><p>There are three variants of extended FABs: small, medium, and large.</p><p>Choose an appropriately-sized extended FAB to add the right amount of emphasis for an action. </p><p>In compact windows with one prominent action, the large extended FAB can be appropriate.</p><p>In larger breakpoints, use a medium or large extended FAB.</p>

## Accessibility

<h2>Use cases</h2><p id="isPasted">People should be able to do the following using assistive technology:</p><ul><li>Navigate to and activate the extended FAB</li></ul>

<h2><span style="white-space:pre-wrap">Interaction &amp; style</span></h2>

<p id="isPasted">To make it easier for users of screen readers to reach a primary action such as an extended FAB, consider placing the action in the upper left region of large web screens, like in an <app-froala-tooltip-element description="Expanded navigation rails show text labels and an extended FAB, and can be default or modal." link-label="More on navigation rails" link-url="/m3/pages/navigation-rail/overview" should-open-link-in-new-tab="true">expanded navigation rail</app-froala-tooltip-element>.</p><p>In smaller windows, the best place for the extended FAB is the lower right corner of a screen.</p>

<p>Extended FABs can be placed in the expanded navigation rail</p>

In a compact window, the Compose FAB is placed on the lower right region in an email app.

<p>Place extended FABs in an easy-to-reach place that doesn’t obstruct other actions</p>

<h2><span style="white-space:pre-wrap">Initial focus</span></h2><p id="isPasted">Ensure the extended FAB is prioritized in the overall focus order to create an efficient experience for people who navigate UIs with assistive tech. </p><p>On mobile, the focus order may start with the <app-froala-tooltip-element description="App bars contain page navigation and information at the top of a screen" link-label="More on app bars" link-url="/m3/pages/app-bars/overview" should-open-link-in-new-tab="true">app bar</app-froala-tooltip-element>, move to the <app-froala-tooltip-element description="Navigation bars let people switch between UI views on smaller devices." link-label="More on navigation bars" link-url="/m3/pages/navigation-bar/overview" should-open-link-in-new-tab="true">navigation bar</app-froala-tooltip-element>, and then skip past any other content on the page to land on the extended FAB.</p><p>When using an extended FAB, both the visible label and icon should be treated as one focusable element. The extended FAB doesn’t need a tooltip because it already has a visible label.</p>
