## Overview

<ul><li><p>Icon buttons must use a system icon with a clear meaning</p></li><li><p>Two variants: default and toggle</p></li><li><p>Many configurations: Color, size, width, and shape</p></li><li><p>On web, display a tooltip describing the action while hovering</p></li><li><p>In toggle buttons, use the outlined style of an icon for the unselected state, and the filled style for the selected state</p></li></ul>

<h2><span style="white-space:pre-wrap" id="isPasted">M3 Expressive update</span></h2>

<p><strong>May 2025</strong></p><p>Icon buttons now have a wider variety of shapes and sizes, changing shape when selected. When placed in <app-froala-tooltip-element description="Button groups organize buttons and add interactions between them." link-label="More on button groups" link-url="/m3/pages/button-groups/overview" should-open-link-in-new-tab="true">button groups</app-froala-tooltip-element>, icon buttons interact with each other when pressed. <a href="https://m3.material.io/blog/building-with-m3-expressive" target="_blank" rel="noopener noreferrer">More on M3 Expressive</a></p>

(filled, tonal, outlined, standard)</p></li></ul><p>Shapes:</p><ul><li><p>Round and square options</p></li><li><p>Shape morphs when pressed</p></li><li><p>Shape morphs when selected</p></li></ul><p>Sizes:</p><ul><li><p>Extra small</p></li><li><p>Small (default)</p></li><li><p>Medium</p></li><li><p>Large</p></li><li><p>Extra large</p></li></ul><p>Widths: </p><ul><li><p>Narrow</p></li><li><p>Default</p></li><li><p>Wide</p></li></ul>

<h3>Color</h3><p>There are four icon button color styles, in order of emphasis:</p><ol class="decimal"><li id="isPasted">Filled</li><li id="isPasted">Tonal</li><li id="isPasted">Outlined</li><li id="isPasted">Standard</li></ol><p>For the highest emphasis, use the filled style. For the lowest emphasis, use standard.</p>

<p id="isPasted">Use the <strong>filled</strong> style for visual impact and key actions that require high emphasis.<br /><br />Avoid overusing the filled style on a screen. Use them sparingly.</p>

<p>Use the <strong>tonal</strong> style as a middle ground between filled and outlined icon buttons. It’s useful for secondary actions paired with a high emphasis action.<br /><br />For example, use the tonal style for actions like <strong>Raise hand </strong>in a video meeting. It’s useful when the button isn’t the main focus of the interaction, such as browsing through sets of cards.<br /><br />Use the <strong>standard</strong> style for low-emphasis buttons, or when placing buttons on a colorful surface.</p>

<h3>Size &amp; width</h3><p>Icon buttons are available in five different sizes:</p><ul><li>Extra small - 32dp</li><li>Small - 40dp (default)</li><li>Medium - 56dp</li><li>Large - 96dp</li><li>Extra large - 136dp</li></ul><p>And three widths:</p><ul><li>Default</li><li>Narrow</li><li>Wide</li></ul><p>Use size and width to provide emphasis and visual hierarchy in a page with multiple buttons. The main action should be the most visually prominent, whether through color or size, like starting and stopping a timer or playing and pausing a song.</p>

<h4>Icon accessibility requirements</h4><p><span style="white-space:pre-wrap" id="isPasted">For selected toggle buttons, if a filled version of an icon doesn’t exist, increase the icon weight to semibold. This requirement doesn't apply to default non-toggle buttons.</p>

## Accessibility

<p>People should be able to do the following using assistive technology:</p><ul><li>Understand meaning of the icon</li><li>Navigate to and activate an icon button</li><li>When applicable, a tooltip should be available to help describe the icon button's purpose</li></ul>

<h2><span style="white-space:pre-wrap">Layout &amp; density</span></h2>

<p>Groups of similar components can be nested together inside a component, or they can stand alone.<br /><br />The target size of each icon button should be at least 48dp, even when nested.</p>

Icon buttons with 48dp target sizes.

<p><span style="white-space:pre-wrap">Icon buttons can be used within other components, such as an app bar</span></p>

imageUrl: https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fm0c1h7ba-4.png?alt=media

<h3 id="isPasted">Avoid applying density by default</h3><p id="isPasted">Don't apply density to icon buttons by default. This lowers their targets below the required 48x48 CSS pixels minimum size. </p><p>Provide density options that allow people to choose a higher density, such as selecting a denser layout or changing the theme. Controls for adjusting density must maintain a target size of at least 48x48 CSS pixels.</p>
