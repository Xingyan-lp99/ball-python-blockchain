<h2>Usage</h2>

<p>There are two variants of button groups: <strong>standard</strong> and <strong>connected</strong>. <br /><br /><strong>Standard button groups</strong> add interaction between adjacent buttons so they respond to each other. When a button in a standard group is selected:</p><ul><li><p>The selected button changes shape and width</p></li><li><p>A selected toggle button also changes color</p></li><li><p>Adjacent buttons move and temporarily change width</p></li></ul>

A welcome screen with a colorful standard button group. 2 pink icon buttons are narrow, and 1 purple button is labelled “Get started".

<p><span style="white-space:pre-wrap">Button groups add more expression to a product</span></p>

imageUrl: https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fm0di4v84-1.png?alt=media

<p>Mix and match the different  button variants, widths, and colors to emphasize what’s important, and to visually group related buttons.<br /><br />By default, all buttons in a standard group should be the same size (XS to XL) and shape (round or square).</p><ul><li><p>Only use multiple sizes in a group for hero moments</p></li><li><p>Avoid mixing sizes frequently</p></li><li><p>Only use a different shape in a group when a button is selected, or to add meaning or contrast</p></li></ul>

A standard button group with 3 buttons of different colors but the same square shape.

<p><span style="white-space:pre-wrap">Use the same shapes for buttons in a group, but change other properties like width and color</span></p>

imageUrl: https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fm0diaau3-same%20shapes.png?alt=media

A standard button group with 3 buttons, including a round primary button. A square button is used to add items.

<p><strong>Connected button groups</strong> help people select options, switch views, or sort elements in a page. </p><p>They behave similarly to standard groups, except they don’t affect adjacent buttons.</p><p>Connected groups should replace the <app-froala-tooltip-element description="Segmented buttons help people select options, switch views, or sort elements. Note: They're deprecated in the expressive update. Use a nav rail instead." link-label="More on segmented buttons" link-url="/m3/pages/segmented-buttons/overview" should-open-link-in-new-tab="true">baseline segmented button</app-froala-tooltip-element>, which is no longer recommended.</p>

<h2><span style="white-space:pre-wrap" id="isPasted">Adaptive design</span></h2>

<p>Adaptive design allows an interface to respond or change based on context, such as the user, device, and usage. <a href="/m3/pages/layout-overview/adaptive-design/" target="_blank">More on adaptive design</a></p>

<h3>Resizing</h3><p>Button groups should move through layouts together in a single line. They shouldn’t wrap to a second line. Multiple button groups can be stacked to keep items close together. However, button groups don’t interact vertically.</p><p>Button groups and individual buttons can be set to <strong>fixed</strong> or <strong>flexible</strong> resizing:<br /></p><ul type="disc" style="list-style-type:disc"><li><p><strong>Fixed</strong>: Manually define the button width (narrow to wide), size (XS to XL), or padding at each breakpoint.<br /></p></li><li><p><strong>Flexible</strong>: Automatically increase or decrease the width of buttons and the button group. Button groups grow until all flexible buttons are at their largest width.</p></li></ul><p>If adjusting button width manually, avoid stretching icon buttons beyond the wide setting.</p>

Two button groups, each with distinct width, size, and padding adjusted to fit two different window sizes.

<p>Buttons can have width, size, and padding manually adjusted to fit different breakpoints</p>

imageUrl: https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fgoogle-material-3%2Fimages%2Fm0djrht4-1.png?alt=media

<p>In <app-froala-tooltip-element description="Window widths smaller than 600dp, such as a phone in portrait orientation." link-label="More on compact breakpoints" link-url="/m3/pages/breakpoints/compact" should-open-link-in-new-tab="true">compact windows</app-froala-tooltip-element>, consider using smaller, narrower buttons so all buttons in the button group can fit. In <app-froala-tooltip-element description="Window widths 1200dp to 1599dp, such as desktop." link-label="More on large breakpoints" link-url="/m3/pages/breakpoints/large-extra-large" should-open-link-in-new-tab="true">large</app-froala-tooltip-element> and <app-froala-tooltip-element description="Window widths 1600dp and larger, such as ultra-wide monitors." link-label="More on extra-large breakpoints" link-url="/m3/pages/breakpoints/large-extra-large" should-open-link-in-new-tab="true">extra large</app-froala-tooltip-element> windows, consider using larger, wider buttons to better fill in the available space.</p><p>Flexible buttons or button groups will automatically adjust width.</p>
