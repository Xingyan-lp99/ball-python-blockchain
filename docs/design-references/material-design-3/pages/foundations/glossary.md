Get to know the key terms and concepts behind Material, from A to Z

## Tab 1

<h2>Glossary</h2>

<h3 id="isPasted">Adaptive design</h3><p><span style="white-space:pre-wrap" id="isPasted">A design approach in which the interface changes based on known user, device, or environmental conditions. Adaptive design in Material includes layout and component adaptations.</span></p>

<h3 id="isPasted">App bar</h3><p>A component that displays information and actions at the top of a screen. <a href="/m3/pages/app-bars/overview" target="_blank" rel="noopener noreferrer">Learn more about app bars</a></p>

<h3 id="isPasted">Banner</h3><p>A component displaying a prominent message and related optional actions.</p>

<h3>Button</h3><p>A component helping people initiate actions such as sending an email, sharing a document, or liking a post. <a href="https://m3.material.io/components/all-buttons" target="_blank">Learn more about buttons</a></p>

<h3 id="isPasted">Bottom sheet</h3><p>A component containing supplementary content that’s anchored to the bottom of the screen. <a href="/m3/pages/bottom-sheets/overview" target="_blank" rel="noopener noreferrer">Learn more about bottom sheets</a></p>

<h3 id="isPasted">Card</h3><p>A component containing content and actions that relate information about a subject. <a href="/m3/pages/cards/overview/" target="_blank" rel="noopener noreferrer">Learn more about cards</a></p>

<h3 id="isPasted">Checkbox</h3><p>A component allowing users to select one or more items from a set. Checkboxes can turn an option on or off. <a href="/m3/pages/checkbox/overview" target="_blank" rel="noopener noreferrer">Learn more about checkboxes</a></p>

<h3 id="isPasted">Chip</h3><p>A component for helping people enter information, make selections, filter content, or trigger actions. Chips can show multiple interactive elements together in the same area, such as a list of selectable movie times, or a series of email contacts. <a href="/m3/pages/chips/overview/" target="_blank" rel="noopener noreferrer">Learn more about chips</a></p>

<h3 dir="ltr" id="isPasted">Color: Baseline scheme</h3><p>The <strong>baseline scheme</strong> refers to the group of selected tones that make up the default colors values used for light and dark themes.</p>

<h3 dir="ltr" id="isPasted">Color: Dynamic color</h3><p dir="ltr">A customization feature in which a user-generated color scheme is mapped to an app’s color scheme.</p><p dir="ltr">Dynamic color is reflected in apps that accept user-generated schemes as inputs for color roles in an app. Dynamic color isn’t simply the output of the Material Theme Builder, or an algorithmic color scheme, but is the presence of a changeable color role that renders an app’s appearance dynamic in response to user input.</p>

<h3 dir="ltr" id="isPasted">Color: Extended color </h3><p dir="ltr">A color specified (in addition to key colors) in order to fill color roles for custom schemes. Extended color is a category for idiosyncratic color roles and applications, such as brand expression or conventional (semantic) meanings.</p>

<h3 dir="ltr" id="isPasted">Color: Key color</h3><p dir="ltr">A key color is not an extracted color–it’s a derivation of the source color. Key colors are a concept useful to understanding dynamic color, but are not used in code. The term describes any color that undergoes hue and chroma transformation of a source color. A key color is the basis for a tonal palette.</p>

<h3 dir="ltr" id="isPasted">Color: Scheme</h3><p>Any mapping of color roles to specific tones from a tonal palette. Schemes consist of multiple color roles. A <strong>dark scheme</strong> informally describes a group of colors using the tones from a group of palettes that are mapped for a dark theme.</p><p>Note: A <strong>light scheme</strong> is not the same as a <strong>light theme. </strong><em>See theme.</em></p>

<h3 dir="ltr" id="isPasted">Color: Source color</h3><p>The single color that’s extracted to define all five key colors is called a source color. While it may not be needed in code, it’s a useful distinction for understanding that a dynamic color scheme has its root in one initiating color, AKA hue, chroma, and tone. <strong>Key colors</strong> are defined in relationship to the <strong>source color’s</strong> <em>hue</em>.</p>

<h3 dir="ltr" id="isPasted">Color: Tonal palette</h3><p dir="ltr">A tonal palette comprises a 13-tone range that serves as the basis for mapping tones to specific roles. A tonal palette offers variations in tonality so that a color scheme automatically provides contrast and visual differentiation within any color group, such as primary.</p>

<h3>Color: Tone</h3><p>A grouping of tones are colors with the same hue and chroma. Informally, tone means degrees of lightness. </p><p><strong>In code</strong>: <span class="inline-code">Tone.of(hex code).get(tone) or Tone.of(hue, chroma).get(tone) </span></p><p><strong>In design guidance</strong>: “A change in a color’s tone can be used to distinguish interaction states or visual interest to component elements.”</p>

<h3 dir="ltr" id="isPasted">Color: User-generated schemes</h3><p dir="ltr">An aspect of dynamic color that describes the colors derived and applied from an individual user’s wallpaper selection or Android preset colors.</p>

<h3 dir="ltr" id="isPasted">Condition </h3><p><span style="white-space:pre-wrap" id="isPasted">A signal that determines when and how an adaptive layout or component should adapt.</span></p>

<h3 dir="ltr" id="isPasted">Contrast </h3><p>Difference between colors. For accessibility, contrast refers strictly to the difference in tone. A difference of 40 in tone guarantees a <a href="https://www.w3.org/WAI/standards-guidelines/wcag/" rel="noopener noreferrer" target="_blank">WCAG</a> contrast ratio ≥ 3.0; a difference of 50 in tone guarantees a contrast ratio ≥ 4.5.</p>

<h3 dir="ltr" id="isPasted">Customization</h3><p dir="ltr">A modification made to a UI reflecting an app, OEM, or individual user's visual preferences and brand. Customization can focus on individual UI elements (for example, styling the color of a component or adding optional actions to a template), or it can be implemented globally (for example, applying a set of styles as a theme across the UI).</p>

<h3 dir="ltr" id="isPasted">Dark theme</h3><p dir="ltr">A dark theme is a low-light UI that displays mostly dark surfaces.</p>

<h3 id="isPasted">Data table</h3><p>A component displaying sets of data across rows and columns.</p>

<h3 id="isPasted">Date picker</h3><p>A component that lets users select a date, or a range of dates. <a href="/m3/pages/date-pickers/overview" target="_blank" rel="noopener noreferrer">Learn more about date pickers</a></p>

<h3 dir="ltr" id="isPasted">Design attribute</h3><p dir="ltr">The style aspect that a design token or hard-coded value applies to, such as color or font.</p>

<h3 dir="ltr" id="isPasted">Design guidelines</h3><p dir="ltr">Guidelines are descriptive written and illustrated docs that demonstrate usage and behavior mainly through examples. They're the long-form discussion of specs that help designers and developers with problem-solving and decision-making.</p>

<h3 dir="ltr" id="isPasted">Design specs</h3><p dir="ltr">Specs are annotated designs and docs that specify the values and parameters that define a component or a feature’s coded capabilities.</p>

<h3 dir="ltr" id="isPasted">Design System Package (DSP) </h3><p>An open-format folder structure created by Adobe to help teams share design system information across tools. <a href="https://github.com/AdobeXD/design-system-package-dsp" rel="noopener noreferrer" target="_blank">Learn more about the DSP format</a></p>

<h3 dir="ltr" id="isPasted">Design tokens</h3><p dir="ltr">A design token represents a small, reusable design decision that’s part of a design system's visual style. Tokens replace static values with self-explanatory names. <a href="/m3/pages/design-tokens/overview" target="_blank" rel="noopener noreferrer">Learn more on the design tokens page</a></p>

<h3 dir="ltr" id="isPasted">Design tokens: Context</h3><p>The set of conditions in which tokens can point to non-default values (for example, <strong>dark theme, dense layout</strong>).</p>

<h3 dir="ltr" id="isPasted">Design tokens: Role</h3><p>A shortened version of the system token name (for example, <strong>Secondary container color</strong>; <strong>Headline 1</strong>).</p>

<h3 dir="ltr" id="isPasted">Design tokens: Types</h3><ul><li><strong>Reference tokens</strong>: All available tokenized values. (for example, <strong>md.ref.palette.secondary200</strong>)</li><li><strong>Component tokens</strong>: Component tokens define the design attributes of elements in a component, such as the color of a button container</li><li><strong>System tokens</strong>: The choices or roles that make the system, from color to typography, elevation, and shape. (for example, <strong>md.sys.color.secondary-container</strong>)</li></ul>

<h3 dir="ltr" id="isPasted">Design tokens: Value</h3><p dir="ltr">The information defining a design attribute, either stored in a token or hard-coded.</p>

<h3 id="isPasted">Dialog</h3><p>A component providing important prompts in a user flow. They can require an action, communicate information, or help users accomplish a task. <a href="/m3/pages/dialogs/overview/" target="_blank" rel="noopener noreferrer">Learn more about dialogs</a></p>

<h3 id="isPasted">Divider</h3><p>A thin line that groups content in lists and layouts. <a href="/m3/pages/divider/overview" target="_blank" rel="noopener noreferrer">Learn more about dividers</a></p>

<h3 dir="ltr" id="isPasted">Element </h3><p dir="ltr">The part of the component that a token or value applies to, such as the container or label text.</p>

<h3 id="isPasted">Extended FAB</h3><p>A component for helping people take primary actions. They're wider than FABs to accommodate a text label and larger target area. <a href="/m3/pages/extended-fab/overview/" target="_blank" rel="noopener noreferrer">Learn more about extended FABs</a></p>

<h3 id="isPasted">Floating action button (FAB)</h3><p>A component representing the most important action on a screen. They put key actions within reach. <a href="/m3/pages/fab/overview/">Learn more about FABs</a></p>

<h3 dir="ltr" id="isPasted">HCT</h3><p>HCT is an abbreviation of hue, chroma, tone. It’s the name of the color space that enables dynamic color. HCT is based on CAM16 <strong>hue</strong> and <strong>chroma</strong>; the L* construct for luminance from L*a*b* (CIELAB, 1976) is denoted as T for <strong>tone</strong>.</p>

<h3 id="isPasted">Image list</h3><p>A component displaying a collection of images in an organized grid.</p>

<h3 id="isPasted">Libraries</h3><p>Developer libraries supported by Material 3 include Android and Jetpack Compose, with in-progress support being developed for Flutter and Web.</p>

<h3 id="isPasted">List</h3><p>A component comprised of continuous, vertical indexes of text or images. <a href="/m3/pages/lists/overview" target="_blank" rel="noopener noreferrer">Learn more about lists</a></p>

<h3 dir="ltr" id="isPasted">Material Components</h3><p dir="ltr">Open-source UI elements created to help developers implement Material Design across Android, Flutter, and the web.</p>

<h3 dir="ltr" id="isPasted">Material Design</h3><p dir="ltr">Material is an adaptable system of guidelines, components, and tools that support the best practices of user interface design. Backed by open-source code, Material streamlines collaboration between designers and developers, and helps teams quickly build beautiful products. </p><p dir="ltr">Material was launched in 2014 and has evolved over the years.</p><p dir="ltr"><strong>Material Design 1</strong> (M1): The first generation of Material Design, launched in 2014, is archived and accessible at: material.io/archive/guidelines.</p><p dir="ltr"><strong>Material Design 2</strong> (M2): The second generation of Material Design, launched in 2018, introduced Material Theming and code for Material Components.</p><p dir="ltr"><strong>Material Design 3</strong> (M3): The third generation of Material, launched in 2021, includes the Material You features like dynamic color. </p><ul><li><p><strong>Material You</strong>: The new Material visual style and set of features embracing the personal and expressive needs of individual users, part of Material Design 3</p></li></ul>

<h3 dir="ltr" id="isPasted">Material Theming</h3><p dir="ltr">The ability to systematically customize Material Design to better reflect your product’s brand.</p><p>While a scheme represents selections or a subset of a single style group, <strong>theme</strong> describes a set of multiple styles and attributes in combination. Themes adjust global styles to adjust for a given user context or preference, such as low light or high contrast. For example, <strong>dark theme</strong> describes design decisions beyond color since adjustments to elevation and state are also integral to expressing a dark UI effectively.</p>

<h3 id="isPasted">Menu</h3><p>A component that displays a list of choices on a temporary surface. <a href="/m3/pages/menus/overview">Learn more about menus</a></p>

<h3 dir="ltr" id="isPasted">Mode</h3><p>Binary setting provided by a system to help people use the device better. Examples: <strong>Focus mode</strong>, <strong>airplane mode</strong>, and <strong>battery saver mode</strong>.</p>

<h3 id="isPasted">Navigation bar</h3><p>A component offering a persistent and convenient way to switch between primary destinations in an app. <a href="/m3/pages/navigation-bar/overview/" target="_blank" rel="noopener noreferrer">Learn more about navigation bars</a></p>

<h3 id="isPasted">Navigation drawer</h3><p>A component providing ergonomic access to destinations in an app. <a href="/m3/pages/navigation-drawer/">Learn more about navigation drawers</a></p>

<h3 id="isPasted">Navigation rail</h3><p>A component providing access to primary destinations in apps when using tablet and desktop screens. <a href="/m3/pages/navigation-rail/overview/" target="_blank" rel="noopener noreferrer">Learn more about navigation rails</a></p>

<h3 id="isPasted">Progress indicator</h3><p>A component displaying an unspecified wait time or the length of a process. <a href="/m3/pages/progress-indicators/overview" target="_blank" rel="noopener noreferrer">Learn more about progress indicators</a></p>

<h3 id="isPasted">Orbiter</h3><p><span style="white-space:pre-wrap" id="isPasted">Floating UI elements that control the content within spatial panels.</span></p>

<h3 id="isPasted">Pane</h3><p>The building blocks of a layout. Content and actions are grouped into panes, which adapt the content to best fit the screen.</p>

<h3 id="isPasted">Radio button</h3><p>A component allowing users to select one option from a set. <a href="/m3/pages/radio-button/overview" target="_blank" rel="noopener noreferrer">Learn more about radio buttons</a></p>

<h3 dir="ltr" id="isPasted">Role</h3><p>Short nickname describing the purpose of a design token within a design system. Also known as slots. Examples: <strong>On surface</strong>; <strong>Body 1</strong>.</p>

<h3 id="isPasted">Side sheet</h3><p>A component containing supplementary content that’s anchored to the left or right edge of the screen.</p>

<h3 id="isPasted">Slider</h3><p>A component that allows users to make selections from a range of values.</p>

<h3 id="isPasted">Snackbar</h3><p>A component that provides brief messages about app processes at the bottom of the screen. <a href="/m3/pages/snackbar/overview/" target="_blank" rel="noopener noreferrer">Learn more about snackbars</a></p>

<h3 id="isPasted">Spatial</h3><p>Relates to the placement of UI in space through extended reality (XR).</p>

<h3 dir="ltr" id="isPasted">Style</h3><p dir="ltr">One or more properties, typically customizable, that define an aspect of a UI's appearance, such as <a href="/m3/pages/color" target="_blank" rel="noopener noreferrer">color</a>, <a href="/m3/pages/typography/overview" target="_blank" rel="noopener noreferrer">typography</a>, or shape.</p>

<h3 id="isPasted">Switch</h3><p>A component that toggles the state of a single item on or off. <a href="/m3/pages/switch/overview" target="_blank" rel="noopener noreferrer">Learn more about switches</a></p>

<h3 id="isPasted">Tab</h3><p>A component used to organize content across different screens, data sets, and other interactions. <a href="/m3/pages/tabs/overview">Learn more about tabs</a></p>

<h3 id="isPasted">Text field</h3><p>A component that lets users enter and edit text. <a href="/m3/pages/text-fields/overview" target="_blank" rel="noopener noreferrer">Learn more about text fields</a></p>

<h3 dir="ltr" id="isPasted">Theme</h3><p dir="ltr">A set of styles, such as color, elevation, and type, that can be applied globally to an app's UI components as a way to consistently adjust aspects of appearance in an app.</p>

<h3 id="isPasted">Time picker</h3><p>A component that helps users select and set a specific time. <a href="/m3/pages/time-pickers/overview" target="_blank" rel="noopener noreferrer">Learn more about time pickers</a></p>

<h3 id="isPasted">Toolbar</h3><p>A component displaying navigation and key actions at the bottom of mobile screens. <a href="/m3/pages/toolbars/overview" target="_blank" rel="noopener noreferrer">Learn more about toolbar</a></p>

<h3 id="isPasted">Tooltip</h3><p>A component that displays informative text when users hover over, focus on, or tap an element.</p>

<h3 id="isPasted">XR</h3><p>Extended reality includes UI viewed in virtual reality or in passthrough blended with the physical environment.</p>
